# 团本活动复盘

统一站点：https://springmirage.github.io/raid-audit/

本仓库是 M6、M7、M8 后续内容的统一维护源，不再向三个旧站分别更新。

- `m6/`：双子毒牙，原完整页面内含历史日期、机制与筛选。
- `m7/`：盘卷祭坛，活动日数据与专项渲染脚本完整保留。
- `m8/`：乌拉特克，五模块团长页、历史页、归档及归档工具。
- `shared/`：所有页面共用的顶部导航样式和标题脚本。

## 更新约定

1. 后续复盘直接修改本仓库对应 `m6/`、`m7/`、`m8/` 目录。更新数据时保留以往活动日与归档，M8 追加版本而不是覆盖旧版本。
2. 每个 HTML 的 body 首项保留相同顶部导航，标签顺序为 M6 双子毒牙、M7 盘卷祭坛、M8 乌拉特克，仅当前页选中态不同。
3. 旧 M6/M7 地址及 RaidNotice 下 M8 仍可访问，保留迁移前版本；它们不自动与新站双向同步。请不要继续更新旧仓库，也不要以旧页面覆盖新站。
4. 如发现旧仓库仍有人更新，先运行 `python tools/check_legacy_sources.py` 只读比较来源版本，人工核对后将所需变更合入本仓库。脚本不会修改或覆盖文件，不设定时任务。
5. GitHub Pages 从本仓库 `main` 根目录发布。推送经用户授权的改动后，等待 Pages 构建成功，再核验线上对应子页、筛选和历史。
6. 顶部导航与现有页面相互独立，不更改原机制判断、人员、计数或原始证据。

## 迁移记录

`migration-manifest.json` 保存一次性导入时的来源提交、每个文件原始 SHA-256、导入后 SHA-256。全部来源均为已经公开的页面仓库。除 HTML 插入顶部导航、统一标题和新地址 canonical 外，其余源文件逐字节保留。旧站不删除、不改写、不重定向。本仓库不依赖旧站才能加载。

M8 原有归档测试：`python -m unittest discover -s m8/tools -p "test_*.py"`。
